# Generative AI with LangChain 🚀

## 📌 About This Repository

This repository documents my learning journey through **Generative AI with LangChain**, following the [CampusX YouTube course](https://www.youtube.com/playlist?list=PLKnIA16_RmvaTbihpo4MtzVm4XOQa0ER0).

The primary goal of this repository is to develop a practical understanding of how Large Language Models (LLMs) work within real-world applications and how to build intelligent AI-powered systems using LangChain.

It contains my learning notes, Python implementations, code experiments, and hands-on projects covering the core concepts of Generative AI.

## 🎯 Learning Objectives

- Understand the fundamentals of Generative AI and Large Language Models (LLMs).
- Learn how LangChain simplifies the development of LLM-powered applications.
- Work with different LLM providers and model integrations.
- Design effective prompts and generate structured outputs.
- Build chains and workflows using LangChain Expression Language (LCEL).
- Understand document processing and semantic search.
- Explore embeddings, vector stores, and retrievers.
- Implement Retrieval-Augmented Generation (RAG) systems.
- Build AI applications using tools and tool calling.
- Understand and develop AI agents.

## 💻 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/abdullah-621/Generative-AI-with-LangChain.git
```

**2. Navigate to the project directory**

```bash
cd Generative-AI-with-LangChain
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the environment**

Windows:

```bash
venv\Scripts\activate
```

Linux / macOS:

```bash
source venv/bin/activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Configure environment variables**

Create a `.env` file and add the required API keys:

```env
OPENAI_API_KEY=your_api_key_here
```

Never commit API keys or other sensitive credentials to GitHub.
